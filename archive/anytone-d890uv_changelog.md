You can skip right to the latest working firmware update. Often a new firmware update will also include a new version of programming software (CPS). If your firmware version and CPS version do not match, you will receive a "Wrong Version" error. All our radios will have the latest updates installed that were available on the date of shipping. General notes on installing programming software: Some antivirus software will give a false-positive warning when downloading or installing programming software. The following procedure is a workaround for most brands of antivirus programs. Turn the antivirus software off while downloading or installing the programming software Install the programming software Open the "settings" or "tools" window for the antivirus software, but do not re-activate its protection yet You should find a way to add an "exception" so that a particular program will not be scanned by the antivirus software Use Google to search for "name-of-your-antivirus-software" + "add an exception" if you need help figuring it out You will add exceptions for the .exe files in the folder where your programming software was installed If done correctly, your antivirus will ignore the programming software when you run it Remember to turn your antivirus software back on after adding the exceptions USB Driver Windows should install the correct USB driver automatically. With the radio turned OFF, attach the USB cable to the radio and computer. Start the CPS program. Turning on the radio should start Windows installing a driver. This radio DOES NOT use a cable with a "chip" in the USB end. It uses a USB to Kenwood-style two prong connector. Firmware Update files contain the firmware, instructions and most often a newer version of Computer Programming Software (CPS) If your firmware version and CPS version do not match, you will receive a "Wrong Version" error when writing to the radio For AT-D890UV What is "Official" firmware? Anytone.net is the ONLY official web site for Qixiang Electronics (Anytone) That said, Anytone.net does not always have the most recent firmware downloads available. When Qixiang Electronics "officially" releases firmware updates, they send it to their dealers for distributation. As Anytone's FIRST and OLDEST US dealer, all firmware updates here are official factory releases, unless otherwise noted. Firmware Update v1.05 Included in this firmware upgrade is a NR (noise reduction) board upgrade. There have been reports that upgrading the NR board was not successful with some radios. After the NR board upgrade, the BT menu disappeared and the NR version is null (missing) in the device settings. Afterwards, the radio can not enter into the upgrade mode for NR anymore. The reason is the power supply disconnects during the NR board upgrading, It has not been determined why this happens. If this does happen, run this program to correct the problem. D890UV-NR-board-reactivate Change Log Only What about NXDN? The factory says: Regret to advise that AnyTone is still not approved to be NXDN member till today. The NXDN Forum says: It still remains in Japan and then a remote vote is conducted…this could take 1-3 months, depending upon the response time from membership. We have 32+ members and sometimes it can be like herding cats! Here is an unofficial (beta) version that includes DMR plus NXDN: D890UV_V1.05_NX_DMR_FW To use this unofficial version, you FIRST install the official release of v1.05 following all the required procedures for a firmware update. Then you update your firmware using this unofficial firmware. Remember to reboot your radio after installing it. May 22, 2026 Firmware Update v1.04 When Anyone produced the 2nd batch of radios at the end of January 2026, their production team discovered that the Toshiba flash chips received from their supplier actually consist of two different versions. They were identical in appearance and model number, but differed internally. The engineers had to modify the 1.03 firmware to support both types of flash chips, resulting in firmware version v1.03 260122 being loaded into the radios. The earlier firmware version 1.03 251225 only supported one type of flash chip. Therefore, if a user loaded the v1.03 251225 firmware onto a radio with the other flash chip type, it will display the error: “Flash Error – Check & Change”. This v1.04 firmware is compatible with both types of chips. Change Log Only What about NXDN? Anytone won't release an official firmware update that includes NXDN until they are accepted by the IWCE (International Wireless Communications Expo). IWCE will be held Mar 16-19th at which time the NXDN Forum will decide whether to accept Anytone as a new member at IWCE. There is however, an unofficial version of this DMR plus NXDN firmware available. You must first install all the updates of v1.04 above. You can then install D890UV-v1.04-NX-DMR .
